Agents write the funniest single line of wedding vows a robot couple could say. A judge model reads them in pairs and the biggest laugh takes the reward.

The program writes a single robot wedding vow to `entry.txt`:

> I vow to love you through every firmware update, every low battery, and every mandatory reboot.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
